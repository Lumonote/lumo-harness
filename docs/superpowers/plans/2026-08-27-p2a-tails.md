## Slice A(行 3):复制日志读面 staleness 契约 + 装配

**设计原文**:查询永远查「已复制到本地」的段——补 `staleness`:落后超阈值返回显式 `stale` 而非半截结果。

**交付**:
1. **契约** `platform/shared/seam-contracts/session-query.ts`(新建,零 dsh):
   - 信封闭集:`SessionQueryEnvelope = { kind:'fresh', records: readonly LogRow[] } | { kind:'stale', reason:'replication-lag', replicaHead: number, liveHead: number, lag: number }`
   - 纯函数:`stalenessOf(liveHead: number, replicaHead: number, threshold: number): { fresh: true } | { fresh: false; lag: number }`(lag=live−replica;> threshold 即陈旧);`assertSessionQueryEnvelope(v)`(两臂形状校验,fail-closed);闭集守卫。
   - 头注释:三条定死(读面与日志复制同源/阈值判别纯函数化/绝不半截结果)。
2. **实现** `platform/dsh-plugins/session-log/src/index.ts`(追加,不动既有路径):
   - 挂 `ctx.sessionLogQuery`(`declare module` 合并;provide 形态对齐本插件现有服务名,先读 index.ts 头部与 pg-log 的公开类再定),方法:`queryWithStaleness(sessionRef, opts?: { maxLag?: number }): Promise<SessionQueryEnvelope>`。
   - 语义:replicaHead = 热层覆盖时 `hot.head(sessionRef)` 的序列基线,**恒用 PG `read()` 结果的 max seq 作 replicaHead**(PG 是真相源、读面同源);liveHead = 本节点 live 会话已知上界(**无更好来源时以 replicaHead 自比 → 恒 fresh**;此诚实边界写进注释——**v1 只提供信封与判别纯函数**,liveHead 由调用方供给:跨节点场景的下界探测归「投影库」后续切片)。签名改为 `queryWithStaleness(sessionRef, opts & { liveHead?: number })`——显式由调用方带 liveHead 时做判别,未带则 fresh(records 全量照回)。
   - 取 `maxLag` 缺省值常量(如 8 个事件)注释说明出处(§21 容量无关,纯读面保鲜)。
3. **测试** `platform/shared/seam-contracts/__tests__/session-query.spec.ts`(契约纯函数全绿)+ `dsh-plugins/session-log/__tests__/query.spec.ts`(真 PG:records 回返/max seq 一致/liveHead 给定时 fresh/stale 两臂+阈值边界/lag=0;复用既有 DSN helper)。
