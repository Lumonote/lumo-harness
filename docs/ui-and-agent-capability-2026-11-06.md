## 本轮实际完成

| 范围 | 结果 |
|---|---|
| 工作台样式 | 项目、资料库、账户等页面统一背景、面板、按钮与间距；减少光晕、渐变和鼠标追踪装饰；提高小字可读性；页签改单行滚动，保留描述的可访问名称 |

| 登录页 | 简化为品牌说明与登录表单双栏；手机保留紧凑品牌区；保留密码、TOTP、Passkey、OIDC 和验证码原行为；64px 验证码切片契约不变 |
| 用量页 | 移除固定白色面板与硬编码图表文字色，继承当前宿主主题；保留平台管理员权限与原统计口径 |
| 团队入口 | 协作页新增目标、三种拓扑、任务主题表单；读取真实 provider/持久任务板/持久消息能力；将请求写入当前原生对话草稿，返回对话后可编辑发送；已有草稿时保留并提示 |
| Bot 接入 | flows 新增签名入口，固定渠道→realm/event 绑定，5 分钟时钟窗口、1 MiB 限额；持久回执与 outbox 同事务；同消息并发或重启后重投复用触发，改内容或改 event 返回 409 |
| 部署与工具 | 可选 `compose.bot.yml` 覆盖文件、无密钥配置示例、Node 签名发送工具；普通控制面 API 保留 Bearer 认证；接入契约见 [bot-ingress.md](./bot-ingress.md) |
| 进程退出 | 独立进程测试发现 flows 捕获 SIGTERM 后 HTTP 仍在监听；补上限时 Shutdown 与超时强制关闭，并等待关闭完成后退出 |

团队入口复用现有 `agent_teams_*` 工具、captain 会话和任务板；没有增加跨节点并发写 TeamState 的 HTTP 管理接口。团队实际执行仍要求节点装配成员 provider，并在真实对话中发送任务。本轮浏览器预览没有调用真实 LLM，也没有声称自动创建过真实团队。

Bot 消息可以驱动已经审核发布的流程。随后新增 `delegation.create`，已验证真实进程经流程作者当前授权创建治理 Task/Run，并在重投和服务重启后复用回执；尚未完成 Bot sender→平台用户/持久 captain/team 的授权桥，也未接入飞书、企业微信等厂商的原生协议与回复接口。connector 的 `tool.invoke` 仍不是 dsh 团队工具。

## 验证证据

- UI、认证与 DDL 套件：主套件 **202 PASS**，另将默认关闭的两份真实 HTTP 认证代理套件以 `LUMO_AUTH_PROXY_TEST=1` 运行，**8 PASS**。合计 **210 PASS / 0 FAIL / 0 SKIP**，覆盖 31 个文件；DDL 的真实 PostgreSQL 结构比较已经运行，新增回执表的 Go/迁移形状一致。
- flows 全模块：真实 PostgreSQL 下 `go test -race -count=1 ./...` 通过；`go vet ./...` 与二进制构建通过。
- Bot 专项：24 路并发同消息只生成一条 outbox；新建服务实例后返回原回执；realm/channel 隔离；篡改 body/ID/时间/渠道拒绝；过期签名拒绝；普通控制面及相似路径仍需认证；超大请求拒绝；回执写入失败时 outbox 回滚。
- HTTP→PG→outbox worker→已发布 webhook 自动化→echo 算子→运行台账的联测通过，重投只执行一次。该用例执行真实引擎与数据库，不调用外部模型或厂商。
- 独立 flows 进程与真实 Node 发送工具联测：首次 202、重复 202 且同 ID、SIGTERM 正常退出、重启后同回执、内容冲突 409、无 Bearer 的普通 API 为 401。
- Compose 的 Standalone / Cluster full / Cluster compact 三种配置合并通过；渠道文件只读挂载，服务专用环境变量进入 flows 子进程。
- 客户端 TypeScript 检查与 UI 客户端/服务端 bundle 构建通过。类型检查使用隔离覆盖层生成声明，并只回投 gitignored 声明产物到开发依赖树；上游跟踪源码、锁文件保持洁净。
- 浏览器使用真实 React 组件与 API 夹具：1440/768/390 三种宽度；资料库、账户、技能、连接器、协作的手机页；两套主题的用量页；验证码正常加载、64×64 切片、三次点选及隐藏字段顺序。已检查页面整体无横向溢出、手机日期控件 16px、没有 pageerror。预览数据不是运行中的生产数据。

本机日志与截图在 gitignored 的 `platform/.build/ui-review/`：`ts-regression.log`、`go-regression.log`、`bot-regression.log`、`bot-process-smoke.json`、`after-*.png`。隔离 PostgreSQL 用后清理，不保留测试服务或渠道密钥。
