# 剩余功能复核（2026-11-07）

本清单按当前源码和最新交付记录复核。`docs/superpowers/plans` 的早期空复选框，
以及 `implementation-status.md` 中明确标为历史的边界，均不能直接当作未开发。
跨节点 Thread 路由、持久事件唤醒、Bot 团队授权及封闭文本上的强制异构审核已存在，
不重复列入待办。

## 本轮已实现并回归

- 资料库文件/目录重命名和移动、元数据 revision 并发校验、上传落库时重新校验目标目录授权；
  API 与整理页面由本轮并行开发补齐。内容 SHA 与元数据 revision 分开比较。
- 项目空间编辑/删除、自动化 revision 乐观锁、全库用户选择器及项目预算管理服务和页面。
  最终测试和页面装配状态以管理功能交付记录为准。
- 协作 Space 的统一权限决策：Governance 解析真实项目归属，再逐请求读取 Collaborator
  的当前直接用户 grant，组合 Realm ∩ Project ∩ Space。来源异常拒绝，未配置不放行。
  合同与部署配置见 [授权判定契约](authorization-contract.md)。
- 项目 owner 的 Space grant 管理接口和页面：四个独立权限、撤回确认、版本 CAS、
  同事务审计、新 grant 固定项目归属，以及成员移出/停用/项目归档后的权限重检。
  WebSocket 在每个输入/输出和空闲检查中复核权限；创建空间不进行跨服务隐式授权。
- Space incarnation 与永久项目认领记录：空间删除、同 ID 重建、跨项目复用均不恢复旧
  grant；重新授权必须显式 CAS。集成 Projects 的旧未绑定 grant 必须迁移；只有完全不带
  Projects 表的独立部署保留 legacy 语义，不能用缺少历史记录证明此前从未绑定。
- 角色动作与继承：单父、最多 32 层、防环、停用截断、deny 优先，任务委派/执行更新
  的策略 API 与页面、revision CAS、当前直接管理员事务内重验和审计均已实现。
  动作、技能使用同一角色解析器；组织管理继续要求直接管理员身份。OPA 可选且只能收窄。
- 动态 owner 支持最新完整历史分支；显式配置后可使用逐次绑定当前登录身份、项目和
  owner 的只读知识工具，本地与签名远程查询均接通。默认档位保持纯文本、无工具。
- 共享 content 正向引用只读审计已实现，覆盖知识资料、治理附件和热会话日志的可识别
  引用；失败、截断及历史缺失会记录为覆盖缺口，所有对象均禁止据此物理删除。

## 仍需开发或验证的能力

| 能力 | 当前范围与准确剩余 |
| --- | --- |
| 内容对象引用生命周期 | 删除资料元数据和检索投影不会物理删除共享 `content/` blob。资料、任务附件、会话日志附件等仍共用内容空间；历史引用覆盖不完整，不能把未登记对象视为零引用。自动 GC 需先统一 pin/release 或隔离新的 managed 命名空间。 |
| 动态用户完整会话能力 | 当前支持认证文本、完成轮次分支及可选当前用户只读知识查询，固定部署模型与本节点工作区。附件、连接器工具、任意模型、宿主机操作及原生交互审批仍未开放。跨副本路由与会话执行租约未实现，配置要求单副本。 |
| 任意交付物的强制异构验收 | 当前可证明范围仅 `platform-closed-text-v1`。当前或历史附件、仓库修改、外部连接器副作用仍无可证完整影响集合，业务完成保持拒绝。扩展前须有服务端完整证据生产者，不能用浏览器或模型自报影响数替代。 |
| 正式恢复审批与租户密钥销毁 | break-glass 有策略无关的内存模型；正式持久审批、双人执行工作流和密钥系统接入仍依赖业务授权与目标系统。生产声明不等于执行链已接通。 |
| 外部身份与供应商联调 | 原生模型配置已与 DeepSeek Harness 对齐，但此前外部调用返回 `AUTH/access-denied`；真实供应商两轮历史和用量尚未通过。OIDC 等实际 IdP 仍需目标端配置及联调。 |
| 物理多主机与生产 HA 验收 | Docker 双节点及本机故障注入已经有证据；不能据此宣称物理跨主机、数据库复制/故障切换、真实证书轮换及生产容量/SLO 通过。 |
| 页面视觉验收 | API/组件测试和 bundle 不代替浏览器视觉与交互核对；仍需对实际部署逐页检查桌面与窄屏、表单冲突、空态及可访问性。 |

Nebula、Doris、全局/集群 Scheduler 的进程拆分不是自动新增功能：已有可选图投影、
PG 分析与租约隔离分别满足当前合同；是否引入额外运维组件或独立进程需要实际负载证据。
本表不把这些已明确的架构选择再登记为代码缺口。
