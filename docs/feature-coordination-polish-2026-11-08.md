# 已有功能协同与交互完整性优化（2026-11-08）

本轮在 `v1.2.1` 继续完善用户、角色、项目、知识库、员工/智能体进度和本机电脑操作之间的衔接。
重点是对象切换后的请求归属、失败后的恢复入口、版本冲突和真实权限事实；未改变分布式架构或数据库结构。

## 项目与任务的连续操作

- 侧栏选择项目会打开真实项目详情；项目创建、改名、资源保存和归档后刷新侧栏目录，失效项目选择会回退到可见项目。
- 协作看板的“协作与运行”跳转到对应任务的授权详情，单次导航意图消费后即清理，已打开的运营工作台同样接收导航。
- 项目详情按项目身份隔离；打开 A 后再打开 B、关闭期间刷新、同项目多个子面板并行保存，都不会被晚到响应覆盖或重新打开旧详情。
- 预算、名称、空间授权及资源回执核对目标和版本。冲突或保存后的刷新失败会保留草稿并锁定相关写入口，要求重新读取。
- 空间、自动化和制品删除使用确认时的名称与 revision/version；后台刷新不会偷偷改成删除新版本。自动化编辑中禁用独立启停，删除编辑对象后清理编辑态。
- 已移出项目的成员只能撤回旧 Space grant，不能继续新增授权；只读用户看到与实际能力一致的说明。

## 组织与委派

- 用户选择器切换初值会清理旧候选，失败后提供原失败页重试；旧目录读取不会覆盖新选择。
- 角色自身及父角色的启停、继承和 revision 变化会刷新权限事实。角色或用户安全写操作遇到 401/403 后，清理旧的敏感事实或可编辑权限。
- 角色保存的未知回执要求重新读取；用户会话撤销期间锁住分页，列表缩页会回退有效页，无效响应不会显示为可操作权限。
- 委派候选按 `worker_id` 选择，修复 Agent 没有人类 `user_id` 时无法正确选中的问题；Go 合法的 `null` 列表按空集合处理。
- 变更任务条件会废弃匹配预览；分发前再次核对输入快照，无合格候选时禁用分发，重复点击只提交一次。旧分发完成不会清掉下一条任务草稿。
- 员工标签读取失败时禁止把空白当成真实画像保存，并提供同员工重新读取入口；切员工后旧读写不会污染新员工，保存标签后废弃旧匹配预览。

## 进度与审核

- 编辑进度期间暂停看板刷新、筛选和切换，已在途的旧刷新失效，避免草稿因父列表刷新而消失。
- 版本冲突保留草稿，并显示最新事实；同一 Run 可显式选择以最新版本继续编辑，新 Run 不复用旧草稿。
- 进度写回执校验 task、run 和 revision。执行审核按当前身份、项目、任务与 Run 隔离，定时或手动重新读取审核状态、Run 和终态结果。
- 团队启动向对话写入草稿失败时保留输入，并显示错误；支持客户端明确拒绝写入的返回值。

## 知识库的真实空间范围

浏览器检索现在把选中空间传入查询服务，身份仍由服务端可信请求解析。`spaces` 只能收窄范围；省略表示不额外按空间收窄，显式 `[]` 返回零结果，不能绕过角色或发布状态检查。

- API 限制最多 64 个空间名称，每项 1–128 字符，允许中文，拒绝控制字符和首尾空白，并去重。
- Vault 的 FTS 和短词 LIKE 路径均在 SQL 排序及 LIMIT 前过滤；Milvus 把空间条件加入远端 search filter，在候选 limit 前生效。Milvus 字符串转义覆盖引号、反斜线和控制字符。
- PG 原有的空间、来源版本及资料权限复核继续保留。远端服务的实际过滤效果仍需部署环境验收，测试中的 Milvus HTTP 回执为模拟响应。
- 切空间、发起新查询或选择另一个片段时，清理旧结果/来源详情并废弃旧请求。资料删除或整理完成后释放旧查询状态，后续查询不会卡住。
- 来源编辑按读取序列隔离，切来源或新建时旧读取不会覆盖当前草稿。保存、删除、重建和 Vault 同步互斥，写入期间禁用相关表单和选择。
- 来源删除增加二步确认并使用确认版本；保存/删除回执校验来源及版本或删除状态。冲突、空回执、网络错误或 5xx 等不确定结果保留草稿，重新读取后才恢复写入口；本地输入错误和明确的 400 可修正后重试。
- 文件上传会同步刷新来源统计；来源变更清理旧检索结果。Vault 来源页补齐可见的全文预览和读取错误，避免点击“查看详情”没有内容显示。

## 电脑操作授权状态

页面校验状态、事件、可渲染时间及授权回执的对话与 revision。状态读取或写入失败后不再用旧 revision 继续授权；成功重读后恢复。登录失效时清空旧状态及事件；切对话、替换客户端服务和 StrictMode 重入均废弃旧请求并清理请求锁。

本轮仅验证授权页面行为，未调用真实电脑操作工具，也未改变 signed-browser 授权接口或使用平台账号接口替代浏览器身份。
