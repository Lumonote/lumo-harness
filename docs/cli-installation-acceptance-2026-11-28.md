# 项目内 CLI 安装验收 · 2026-11-28

## 范围与入口

复用 Agent 工作台「工具与模型 → 工具详情 → CLI 安装」，提供在线安装、指定版本、重装、取消、重试、进度、日志和安装位置。成功后刷新共享工具目录；普通会话、群组和项目流程的新连接从同一注册表读取受管版本。

支持 9 个注册入口：Codex、Claude Code、Codex ACP、Gemini、CodeBuddy、GitHub Copilot、OpenCode、Qwen Code、TRAE CLI。Claude Code 同时安装 ACP 适配器和原生 CLI。WorkBuddy、Kiro 仍走已有本机检测，界面明确说明不支持受管在线安装。
