# 工作台存储规模与可靠性验证

日期：2026-11-28。以下结果来自本机临时夹具，验证群组摘要、历史分页、正文检索与增量载荷；不是用户界面或网络性能承诺。

## 复现命令

在仓库的 `platform/` 目录执行：

```sh
LUMO_RUN_SCALE_REVIEW=1 node node_modules/vitest/vitest.mjs run dsh-plugins/acp-engines/__tests__/conversation-scale_review.spec.ts
```

测试默认跳过，显式启用后输出一行 `LUMO_SCALE_REVIEW` JSON。它创建独立临时目录，在结束时关闭 SQLite 并清理夹具，不读取或改写用户记录。对应测试文件为 `platform/dsh-plugins/acp-engines/__tests__/conversation-scale_review.spec.ts`。

## 测量口径

- 环境：macOS / Darwin 25.3.0、arm64、Node.js 22.22.2；测量机器为 Apple M4、10 核、16 GiB 内存。系统和硬件信息通过 Node.js `os` 模块补查；存储介质型号及后台负载未记录。
- 群组：200 个话题，每个 24 轮、3 个角色；合计 JSON 正文 30,227,619 字节，其中 198 个话题已归档。
- 独立对话：200 个会话，每个 1,200 条事件，合计 240,000 条持久事件。
- 每项先预热 1 次；摘要读取和 200 条历史分页各测 25 次，其余各测 7 次。记录单进程同步操作耗时，采用已写入数据的热缓存。样本较少时，报告的 p95 实际接近样本最大值，不能作为严格尾延迟估计。
- 摘要测试读取独立元数据索引；全量正文测试读取和解析所有话题。全文检索读取匹配作用域内的正文；SQLite 历史分页直接查询指定会话的最近 200 条事件。

## 本次结果

| 操作 | p50 | p95 | 本次存储预算 | 结果 |
| --- | ---: | ---: | ---: | --- |
| 200 个群组摘要 | 0.07 ms | 0.10 ms | p95 < 16 ms | 通过 |
| 200 个群组全量正文 | 35.71 ms | 38.08 ms | 对照项，未设预算 | — |
| 群组正文检索 | 44.12 ms | 55.83 ms | p95 < 250 ms | 通过 |
| 会话历史分页，200 条 | 0.17 ms | 0.19 ms | p95 < 20 ms | 通过 |
| 24 万条事件正文检索 | 81.45 ms | 84.98 ms | p95 < 250 ms | 通过 |

预算用于本轮本地存储评估。基准输出预算判定布尔值，不将对机器负载敏感的时间阈值作为默认 CI 测试门禁；功能测试独立断言检索结果与分页条数。

同一夹具中，一个完整话题为 151,135 字节，单个当前回合为 6,272 字节，回合载荷比完整话题少约 95.85%。此比较未计 SSE 元数据、HTTP 头和压缩，只说明增量事件可减少重复正文传输。首次连接和回放窗口之外的恢复仍需要快照。

测量结束时进程 RSS 约 430.4 MB，包含 Vitest、夹具构造、全部测试对象与 SQLite；它不是产品的增量内存开销，也不能用于证明页面内存占用改善。

## 对应可靠性验证

```sh
node node_modules/vitest/vitest.mjs run dsh-plugins/acp-engines/__tests__/route-flow_review.spec.ts dsh-plugins/acp-engines/__tests__/engine-host_review.spec.ts dsh-plugins/acp-engines/__tests__/event-recovery.spec.ts
```

本次 33 项通过：覆盖流回放、实时事件、快照与心跳遇到慢客户端时停止写入并退订，客户端重连从持久事件恢复；取消 Skill 加载立即结束请求并释放工作区，忽略取消信号的延迟结果不能派发；跨 realm、用户、项目的取消请求被拒绝；还覆盖写入失败重试、旧审批失效、删除后回调和进程释放边界。

慢客户端测试通过受控响应对象模拟 `write()` 返回 `false`，验证逻辑和内存有界的写入策略；没有模拟真实 TCP 缓冲、浏览器网络栈或代理转发。

## 尚未由本次测量覆盖的指标

冷启动和磁盘冷缓存、HTTP 往返与压缩、浏览器首屏和输入响应、长对话 DOM 渲染、真实流式输出、移动设备、慢网络丢包以及多用户并发均未测量。上述存储结果不能替代这些端到端指标；放宽话题与并发容量前应补相同夹具的浏览器和网络测量。
