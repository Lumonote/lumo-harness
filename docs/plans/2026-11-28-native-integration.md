# DSH 与多引擎工作台融合收敛

目标：在公开插件扩展面中统一会话发现、导航、管理和常用交互，保持引擎恢复句柄、原生执行权限和数据来源独立。

1. 使用公开 `sidebar.workspaces`、`sidebar.panellist`、`main` 扩展位，合并 DSH / ACP / 群组的项目与最近记录；原生记录操作继续调用宿主服务，外部记录调用各自 API。搜索、错误、归档和恢复不能跨身份串用。
2. 外部会话与群组共用 composer、命令和审批展示，DSH 对话继续完整使用原生 composer。所有入口以能力是否可用决定，不模拟不支持的引擎能力。
3. 通过现有双通道工具网关补齐知识和连接器能力；绑定真实会话身份，复用来源服务的权限检查和取消语义，审批可在所属对话处理。
4. 删除已能由公开侧栏和分组入口替代的源码覆盖，更新覆盖清单并运行兼容审计。
5. 回归覆盖统一目录与导航、跨身份隔离、共享输入、MCP 调用与审批、插件装配和覆盖层。真实模型与远端验收按实际可用环境记录，外部 403 或未提供服务器不得记为通过。

不修改 `deepseek-harness/` 源码，不复制供应商隐藏上下文，不将本机路径当成远端文件。
