# Personal AI Agents 与管理工作台整合

更新日期：2026-11-28。

> 本文包含此前阶段的行为与验收记录。2026-11-28 后续已补齐持久聊天、草稿、远程任务和设备接入等开发，并通过本机 Claude Code 真实执行验收；以 [本轮开发验收](workbench-acceptance-2026-11-28.md) 和 [ACP 使用说明](../platform/dsh-plugins/acp-engines/README.md) 为当前行为依据。

## 使用入口

- 本地部署在「Agent 工作台」中管理开发工具、可复用 Agent 和协作群组，沿用 `?lumo=agents` 地址。
- 工作台分为「会话与群组」「Agent 通讯录」「开发工具与模型」「独立会话」。可以直接创建角色团队，也可以先保存 Agent，再勾选 2–6 位成员建立群组，选择协调助理并指定已有的本机工作区绝对路径。
- 「设置 → 管理工作台 → 打开管理工作台」集中管理项目与任务、运行环境、能力配置、账户与权限。设置先关闭，再进入管理工作台，避免叠加两个模态窗口。
- 「工作工具」「项目运营」「开放设计」「PPT 生成」均从原生侧边栏和工作台左侧导航移除。
- 创作继续通过原有 `/design`、`/ppt` 命令触发；命令后的创作意图、样例选择及原生技能提交链路保留。
- 历史 `?lumo=market`、`?lumo=operations`、`?lumo=ops` 地址保持可用，前两者现在呈现同一个管理工作台。项目选择和任务详情仍携带一次性的导航目标。

## 对话布局、原生消息与群组外观

Agent 工作台采用左侧记录、右侧对话的布局。左侧按「项目」与「最近对话」组织记录，项目以完整工作区路径分组，可折叠；群组与独立会话在同一列表呈现，成员内部会话不重复列出。最近对话按最近发送时间排序，旧记录回退到创建时间，最多显示 20 条；行内只显示对话标题和活动时间，不再重复项目名。时间复用宿主 `relativeTime`，显示“刚刚 / N 分钟前 / N 小时前”等，每分钟及窗口重新获得焦点时更新；悬停时间可查看本地完整日期，缺失时间显示“时间未知”。全部记录仍可在项目下找到。搜索覆盖项目路径、对话标题及群组最近消息，点击记录直接打开对应对话。独立会话首条可见消息作为默认标题；可恢复会话的标题和活动时间随恢复索引保存。通讯录和工具入口仍保留。右侧显示消息、成员发言标识和固定输入框。新建群组与通讯录配置在需要时打开，右侧常驻图标栏提供项目文件、Skill、群组成员、执行记录和设置入口；独立会话共享文件、Skill、执行记录和会话设置。窄屏通过「会话记录」切换记录栏，避免挤压对话。

用户消息复用宿主公开包 `@deepseek-ai/dsh-client-ui-primitives` 的 `UserMessageBubble`，助手消息使用 `MarkdownText`，支持 Markdown 列表、表格、代码块复制和流式内容；独立会话思考过程使用原生 `DisclosureRow` 折叠展示。React DOM 与原生组件由宿主共享模块提供，插件不打包另一份渲染器。界面跟随宿主主题变量。输入支持 Enter 发送、Shift+Enter 换行，中文输入法组合期间不会误发；阅读较早消息时不会强制滚动到底部。

原生消息包在 `lumo-native-content` 边界内，页面的按钮、表单和焦点样式不再覆盖原生复制按钮、文件链接、图片按钮与 Markdown 复选框；回复标题样式只作用于角色标题。消息滚动区独立建立层叠上下文，原生吸顶代码栏不会穿过群组设置或成员详情面板，窄屏设置面板从对话标题下方对齐展开。

输入框默认单行约 38px，随内容自动增长，上限 144px，清空后收回。附件加号、发送、停止、设置和刷新使用宿主公开图标，保留悬停说明及无障碍名称。项目、角色、发送方式与加号同排，窄屏项目入口只显示文件夹图标。正文沿用宿主默认 14px 与字号偏好，行高收紧为 22px；三级标题采用 15px 基准，代码保持宿主独立代码字号。侧栏、菜单和设置表单统一使用紧凑间距，不放大整页。

## 右侧对话工具

- 项目文件：调用当前会话已授权目录的文件接口，逐级浏览、返回上级、按名称或相对路径筛选；点击文件加入当前消息，再次点击移除。此处提供文件引用，不包含文件编辑或内容预览。
- Skill：按项目读取真实注册目录，搜索、加载、移除，与输入框的上下文标签同步；发送时才展开正文。已选数量显示在图标角标，发送成功清空。
- 群组成员：显示工具 Logo、职责、真实连接状态和模型选择；可以 `@` 点名、连接工具或查看成员的只读执行详情。
- 执行记录：群组显示每轮的真实角色步骤；独立会话显示用户消息、会话事件和随 SSE 更新的工具调用状态。点击记录定位到对应消息；待确认权限显示数量，并提供返回原权限请求的入口。
- 设置：项目选择、群组 Logo 与颜色、模型和会话生命周期操作按会话类型显示。宽屏面板与消息并排，对话区域不足 760px 时覆盖展开，图标栏保持可用；关闭按钮或 Esc 关闭后恢复到入口焦点。

右栏复用公开 `Button`、`Input`、`Tooltip`、`PathLabel`、`StateDot` 与产品图标，使用宿主主题令牌和原生样式边界。插件只负责右栏布局、ACP 数据连接与上下文选择。读取按需触发，失败可重试；切换对话取消目录请求并忽略迟到响应，运行时禁止修改本轮上下文，成员详情保持只读。

## 附件、项目与输入命令

- 加号选择文件，也支持拖入文件和粘贴图片。草稿显示可移除的附件卡片，支持仅发附件；上传失败保留草稿和明确错误，重试复用已上传引用。每消息最多 4 个文件、单文件 8 MiB、合计 16 MiB。
- 文件按 realm、用户和项目身份隔离存储，不将 base64 写入对话记录。支持图片的引擎收到真实图片块，小型文本直接展开，其他文件通过实际文件资源引用送达；群组每个执行角色都会收到附件。每身份范围存储上限 256 MiB。
- 项目选择复用公开工作区列表与原生文件夹选择服务，同时支持手填绝对路径。已有对话切换项目会新建对应项目的对话，保留旧记录；群组配置复用，成员引擎会话重新建立。
- 输入 `/` 搜索命令及当前项目可调用的 Skill；群组支持 `/project`、`/direct`、`/discuss`、`/relay`、`/members`，独立会话支持 `/project`、`/settings`；两者都支持 `/files`、`/skills`、`/activity` 打开相应侧栏。选择 Skill 后形成可移除标签。
- 输入 `@` 选择群组成员或当前项目文件，`@src/` 可逐级展开目录；独立会话提供项目文件引用。方向键选择、Enter/Tab 确认、Esc 关闭，菜单确认不会同时发送消息，中文输入法组合期间不会误选或误发。
- Skill 列表与正文通过宿主公开 `SkillRegistry.snapshot/get` 和 `renderSkillContent` 加载，按真实会话工作区解析，只允许用户可调用项。发送时加载实际正文及资源基址，群组向每个角色传递；历史仅保存名称。目录未就绪可重试，加载失败明确报错并阻止引擎执行。每条最多 4 个 Skill、8 个项目文件；拒绝越出项目目录的引用。

输入菜单复用原生 `MenuSurface`、尺寸定位与图标组件，ACP 会话保留自身协议和状态管理，并非将第三方引擎伪装成 DSH 原生会话。当前通过菜单选取 Skill，不保证第三方工具的全部斜杠命令都能透传执行。独立运行的 ACP 插件未配置 Skill provider 时会明确提示服务未启用；Lumo 嵌入模式已接入宿主 Skill registry。

新群组默认发给协调助理。点击成员或在输入开头输入 `@成员名称 ` 可切换到该角色，继续同一条记录；也可切换讨论、接力。共享上下文包含最近 3 轮的公开问题与已完成答复，每条历史答复最多 2000 字符；不共享私有思考和权限内容。

群组 Logo 可自动组合成员工具标识，也可选择团队、Bot、闪电、代码、星光或成员工具 Logo。颜色支持预设色和原生颜色选择器；空闲时保存到群组记录，左侧记录与右侧标题同步更新，重启后保留。服务端仅接受规定的 Logo 标识和六位十六进制颜色，沿用完整身份范围检查及原子存储；旧记录缺少外观字段时自动使用默认外观。Logo 颜色用于群组图形与背景，彩色工具标识保持品牌原色。

11 个工具入口会自动显示对应品牌 Logo，覆盖目录、通讯录、成员、消息和独立会话。资源来自固定版本 `@lobehub/icons-static-svg@1.106.0`（MIT），以内嵌 SVG 数据随插件打包，无远程图片请求；Codex 与 Codex ACP 共用标识，GitHub Copilot 使用 GitHub Copilot 标识。未知工具显示通用标识。

## 角色如何调用已有引擎

角色协作复用 ACP `EngineHost`、既有 Codex 桥接、权限 Ask broker 和运行树记录。每个角色有独立的真实引擎会话；可以多个角色使用同一个引擎，也可以混合 Claude Code、Codex 等已检测到的引擎。

三种发送方式：

| 方式 | 执行顺序 |
| --- | --- |
| 指定角色 | 仅调用所选角色 |
| 依次协作 | 按角色配置顺序调用 |
| 讨论并汇总 | 其他角色依次执行，协调助理最后汇总 |

当前实现为确定性顺序编排。协调助理负责汇总，不会自行生成任务图、选择其他角色或并行修改文件。下一个角色接收已经完成的公开答复；共享上下文不含私有思考事件或权限请求载荷。界面按实际角色和引擎显示回复，不模拟多个角色发言。

权限请求继续由原有机制审批。停止、失败、超时会阻止后续角色派发；已经完成的外部操作不会回滚。不同角色房间对同一规范化工作区采用互斥执行。

## 开发工具、模型与通讯录

工具目录展示现有注册表中的 Claude Code、Codex、Codex ACP 适配器、Gemini CLI、WorkBuddy、CodeBuddy、TRAE、Kiro、GitHub Copilot、OpenCode、Qwen Code 共 11 个入口，支持搜索与重新检测。区分已安装入口、按需启动适配器和不可用；发现可执行程序不等于已登录或已获模型权限。

「连接并读取模型」在用户指定目录建立临时真实会话，读取能力后关闭，不发送任务。模型来自 ACP `configOptions`，兼容旧版 `models`；Codex 桥接读取 app-server `model/list` 并在 `turn/start` 中传入选择。不维护静态模型名单；目录展示不保证账户有权调用每个模型。未提供列表的工具继续使用自己的配置。

工具页的选择可以带入新 Agent 或独立会话。通讯录支持创建、编辑、移除、模型读取与选择；每份配置包含名称、职责、工具和可选模型。存储以 realm、用户、项目完整范围隔离，最多 64 项；群组保存成员快照及 Agent 来源 ID，后续编辑或移出通讯录不会改写已有群组。

群组成员可先「连接工具与模型」，连接本身不派发任务。空闲时可以切换真实会话模型；执行前重新确认成员配置中的模型。会话恢复索引保存标题和模型选择，恢复时应用所选模型，不支持或已不可用的模型会明确报错。模型切换期间拒绝新回合和并发切换。引擎主动更新配置会同步界面和恢复索引；写入失败会提示。

点击 `@成员` 选择单人回答；「查看成员会话」只观察该成员的流式消息和工具进度，不消费桌面端新会话意图。独立会话列表标明群组归属并提供「进入群组」；群组成员的发送、停止、恢复、关闭和模型修改统一由群组入口处理。活动群组执行期间，其他独立会话不能在相同规范化工作区派发任务。

模型读取会取消已离开页面的请求，迟到响应不能覆盖其他工具、工作区或账号的数据。SSE 模型快照不会反复重建连接。群组成员句柄或模型持久化失败时保留实际状态和控制入口，提示重试保存；临时模型会话关闭失败会明确指向独立会话中的清理入口。

## 状态和恢复

`acp-role-rooms.json` 与会话恢复索引分开保存，采用原子替换和 `0600` 文件权限，包含 Agent 通讯录、群组成员职责、工具与模型配置、公开对话。兼容尚无通讯录字段的旧文件。运行时重启会把未完成回合标记为中断；不会自动重发消息或重新批准工具。通过明确的恢复操作接回可恢复引擎会话。

支持停止协作、恢复会话、释放会话和删除房间。释放保留公开对话；删除清除房间记录。消息 ID 用于防止丢失响应后的重复派发。最终写入失败保留内存回执并提示核对实际引擎结果；会话关闭失败保留可重试的会话句柄。

边界：仅本地部署开放角色协作；每房间 2–6 个角色，最多 16 个房间、每房间 24 轮，输入 6000 字符，单角色公开输出 8000 字符，超出会明确标记截断。单角色等待上限 30 分钟；存储文件上限 32 MiB。引擎安装、登录、工作区访问与并发进程数量沿用现有引擎配置。

## 管理工作台的信息结构

| 分类 | 内容 |
| --- | --- |
| 项目与任务 | 项目资产、流程自动化、协作执行、团队进度；本地模式提供 Agent 工作台 |
| 运行环境 | 本机状态、引擎会话、远端机器；服务器模式提供集群服务、恢复审批、存储配额及平台用量 |
| 能力配置 | 技能管理、技能中心；服务器模式增加连接器、制品目录与灰度 |
| 账户与权限 | 用户中心、用户/部门/角色管理、权限诊断，按部署和已有角色权限显示 |

管理目录支持搜索，功能在同一工作台内切换。项目资产与流程自动化拆开；本地运行状态、引擎会话和 SSH 管理拆开。制品发布与安装计划独立为 `RegistryPanel`，进入该功能后才读取 Registry；项目页不再预加载委派、用户画像、专家和运行状态。业务接口及服务端授权保持原有实现。

主要模块：`management-catalog.ts` 定义分类与权限可见性；`market-surface.tsx` 承担统一管理容器；`settings-management.tsx` 接入宿主公开的 `settings.section` 扩展点。没有修改上游 `deepseek-harness/` 源码。
