  and stores them in the release object, where anyone with `helm get manifest`

  For a production cluster, re-run with --set secrets.create=false and create
  the Secrets below yourself.

{{- if $edgeGateway.enabled }}

  The edge gateway ({{ include "lumo-platform.name" . }}-edge-gateway) is the
  north-south entry point and routes by the table in ConfigMap
  {{ include "lumo-platform.name" . }}-edge-routes. It is a ClusterIP Service by
  default: exposing it is a deployment decision, so set
  `services.edge-gateway.type` (or front it with your own Ingress) rather than
  flipping the global service.type, which would expose every internal service.
    kubectl -n {{ $ns }} port-forward svc/{{ include "lumo-platform.name" . }}-edge-gateway {{ $edgeGateway.port }}:{{ $edgeGateway.port }}
{{- end }}
